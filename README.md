# Portfólio profissional

Portfólio profissional de **Gustavo Figueiredo Soares**, desenvolvido em HTML5 e CSS3 para a disciplina **Design Profissional**.

## Sobre o projeto

Site estático que apresenta meu perfil profissional: apresentação, formação, competências técnicas e comportamentais, projeto, currículo em PDF e links de contato. O projeto faz parte da atividade "Publicação do portfólio profissional e do currículo no GitHub", da disciplina Design Profissional (Prof. Vinicius Alves Rodrigues).

## Objetivos

- Apresentar minha trajetória e minhas competências de forma clara e verdadeira
- Praticar HTML semântico, CSS responsivo e acessibilidade
- Praticar o uso de Git e GitHub (commits, branch e pull request)
- Publicar o site gratuitamente no GitHub Pages

## Tecnologias utilizadas

- **HTML5**: estrutura semântica da página
- **CSS3**: layout com Flexbox e Grid, variáveis de cor, tema claro e escuro automático (`prefers-color-scheme`) e adaptação para celulares
- **Git e GitHub**: versionamento e hospedagem do código
- **GitHub Pages**: publicação do site

Não foram usados frameworks, bibliotecas externas ou JavaScript.

## Estrutura do portfólio

O site tem as seguintes seções: Início, Sobre mim, Formação, Competências técnicas, Competências comportamentais, Projetos, Currículo e Contato, além do rodapé com autoria.

```
portfolio-profissional/
|-- index.html       Conteúdo e estrutura da página
|-- style.css        Aparência (cores, fontes, layout)
|-- README.md        Documentação do projeto
`-- assets/
    `-- curriculo.pdf  Currículo em PDF
```

## Projetos apresentados

### Gestão de Vendas

Automação em Python que usa Selenium para ler mensagens do WhatsApp Web e gravá-las em uma planilha do Excel. Foi criada para ajudar a mãe de um amigo a organizar informações de aluguel de imóveis. Trabalho em grupo, no qual dei a ideia e ajudei na parte de uso do Selenium.

- **Tecnologias:** Python, Selenium e openpyxl
- **Repositório:** https://github.com/gustavofigueired07/gestao_vendas
